인공위성

여러분은 국제우주정거장(ISS)이나 허블 우주망원경에 대해서 들어보았을 것이다. 만약 이들 인공위성체를 직접 확인할 수 있다면 매우 재미있을 것이다. 실제로 국제우주정거장이나 허블 우주망원경과 같은 큰 인공위성은 초저녁 또는 새벽에 -3, -4 등급으로 밝게 빛난다. 인공위성의 궤적만 알 수 있다면 얼마든지 관측 가능하다.

인공위성은 해가 진 직후 또는 해가 뜨기 직전 관측 가능하다. 즉 우리는 해를 보지 못하지만 인공위성은 해를 받아 빛날 때가 관측 적기이다. 인공위성의 궤적을 보면서 관측 적기를 찾아서 관측해보자.

인공위성의 표시

성도에 인공위성을 표시하기 위해서는 아래의 순서를 따르면 된다.

  1. [보기][인공위성....] 메뉴를 선택한다. 또는 도구바에서 인공위성을 클릭한다.
  2. 아래와 같은 인공위성 윈도가 열릴 것이다.
    인공위성 자료 보기
  3. 왼쪽의 인공위성 목록에서 보고자 하는 인공위성을 더블 클릭하면 오른쪽의 보여질 인공위성 목록에 해당 인공위성 이름이 나타난다. 두 개 이상의 인공위성을 선택해도 된다.
  4. 확인 버튼을 눌러 인공위성 윈도를 닫으면 보여질 인공위성 목록의 첫 번째 인공위성이 성도의 중심으로 온다.
  5. 만약 두 개 이상의 인공위성을 선택했고, 두 번째 인공위성을 보고 싶다면 동서남북바의 왼쪽 아래에 있는 [찾기] 버튼을 누른다.
  6. 찾기 윈도가 열리면 맨 위의 레디오 버튼 '태양계 대상'을 클릭한다. 이 때 목록에는 태양, 달, 행성 및 성도에 보여지는 혜성, 소행성, 인공위성의 이름이 나타난다.
  7. 목록에서 두 번째 인공위성의 이름을 더블 클릭한다.
  8. 성도의 중심에 찾는 대상이 보일 것이다. 만약 보이지 않는다면 도구바에서 [태양계], [태양계 이름]이 선택되어 있는지 확인한다.

새로운 인공위성 자료의 입력

인공위성 목록에 포함되지 않은 인공위성을 보고자 할 때는 다음의 순서를 따른다.

  1. 인공위성의 궤도요소를 얻는다. 인공위성의 궤도요소는 적어도 2주일 단위로 새로운 자료를 입력해야 한다. 인공위성의 자료는 미국의 NASA에서 얻을 수 있다.
  2. 인공위성 윈도를 열고, 인공위성의 이름을 입력한다. 이름은 인공위성 목록에 없는 새로운 것이어야 하며, 만약 같은 이름이 있을 경우 기존의 자료는 지워지고 새로운 자료로 변경된다.
  3. Epoch of Element를 연, 월, 일 단위로 입력한다. '시간:분' 단위는 아래의 공식에 따라 '일' 단위로 바뀌어야 한다.
     일 = 시간 / 24 + 분 / 1440
  4. 기타 궤도요소를 입력한다. 등급 인수는 위치 계산에는 사용되지 않으므로 위치 계산만을 목적으로 할 때는 입력하지 않아도 된다.
  5. 저장 버튼을 누르면 현재의 자료가 저장되고, 왼쪽의 인공위성 목록에 새로 입력한 인공위성 이름이 보일 것이다. 만약 인공위성의 이름이 이미 존재하면, 기존의 자료를 바꿀 것인지 묻는 메시지 박스가 열릴 것이다. 여기서 확인 버튼을 누르면 기존의 자료를 바꾼다.
  6. 만약 새로 입력한 인공위성을 보고자 할 때는 인공위성의 목록에서 인공위성 이름을 더블 클릭한다.
  7. 확인 버튼을 눌러 인공위성 윈도를 닫는다. 취소 버튼을 눌러도 인공위성의 자료는 저장된다.

인공위성 자료의 변경, 삭제

인공위성의 궤도요소는 계속해서 보정된 값이 제공되므로 가장 최근의 궤도요소를 입력하여 사용해야 한다. 궤도요소는 적어도 두 주일에 한 번은 변경해야 한다. 즉 Epoch of Element가 계산하고자 하는 날짜보다 두 주일 이내에 있어야 한다. 이미 입력된 자료의 변경은 다음과 같다.

  1. 인공위성 윈도에서 자료를 변경하고자 하는 인공위성을 인공위성 목록에서 선택(클릭)한다.
  2. 상세 정보란에 선택된 인공위성의 정보가 나타난다.
  3. 여기서 변경하고자 하는 자료 값을 변경한다. 단 인공위성 이름을 변경하는 것은 새로운 인공위성 자료를 입력하는 것을 의미한다.
  4. 저장 버튼을 누른다. 만약 인공위성 이름은 바꾸지 않았다면 기존의 자료를 지우고 새 자료로 바꿀 것인지를 묻는 메시지 박스가 열릴 것이다. 확인 버튼을 누르면 새 자료가 변경되어 저장된다.
  5. 만약 현재 있는 인공위성을 지울 때는 지울 인공위성을 인공위성 목록에서 선택하고 '파일에서 지움' 버튼을 클릭하면 된다. 한 번 지워진 자료는 다시 복구할 수 없으므로 지울 때는 신중을 기해야 한다.
