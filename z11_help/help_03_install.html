설치

설치 방법

별바라기는 Microsoft Windows 기반의 OS에서 설치 가능하다. 설치 방법은 아래와 같다.

  1. 원하는 위치에 별바라기 설치 디렉토리를 만든다. 디렉토리 명은 무엇이든 가능하다.
  2. 해당 디렉토리에 다운받은 ZIP 파일의 압축을 푼다.
  3. 해당 디렉토리 아래 'Program/StarFlower.exe' 파일을 실행한다.
  4. 만약 'side-by-side...'로 시작하는 오류 메시지가 보일 경우, vcredist_x86.exe 파일을 실행하여 설치한다.
  5. 설치가 완료되었다.

최저 사용 환경

별바라기는 다음의 환경을 필요로 한다.

  • Microsoft Windows 10 운영 체제를 권장한다.

디렉토리 구조

별바라기 설치가 끝나면 별바라기 홈 디렉토리 아래에 Data, DeepskyPhoto, Program, GSC, Sample 다섯 개의 디렉토리가 만들어진다.

  • Data: 프로그램의 실행에 필요한 각종 자료가 저장된다.
  • DeepskyPhoto: 멋진 우주의 모습을 보여주는 사진.
  • GSC: GSC 자료가 저장되는 디렉토리이다. 이 디렉토리는 프로그램에서 바꿀 수도 있다.
  • Program: 별바라기 실행 파일인 'StarFlower.exe' 및 도움말 파일, ini 파일, readme.txt 파일이 저장된다.
  • Sample: 별바라기를 이용하여 만든 성도가 저장되어 있으며, 이 파일은 별바라기를 이용하여 열어볼 수 있다.

윈도 용어 설명

  • 클릭: 왼쪽 마우스 버튼을 눌렀다 놓는 것을 가리킨다. 보통 '마우스 클릭'이라고 하면 왼쪽 마우스 버튼을 가리키며 오른쪽의 경우에는 오른쪽 마우스 버튼이라고 지시한다.
  • 더블클릭: 왼쪽 마우스 버튼을 빠르게 두 번 연속하여 클릭하는 것을 가리킨다.
  • 오른쪽 마우스버튼: 오른쪽 마우스 버튼은 클릭 된 대상의 속성을 보여주는 역할을 한다. 별바라기에서는 클릭 된 대상의 정보를 보거나 대상을 성도의 중심으로 옮길 수 있다.
  • 드래그: 마우스 버튼을 누른 상태에서 마우스를 이동하는 것을 가리킨다. 별바라기에서는 궤적의 날짜를 옮길 때 사용된다.
  • 레디오 버튼: 둥근 원으로 표현되며 여러 가지 중에서 하나만을 선택할 때 사용된다. 별바라기에서는 [선택사항][성도보기...] 메뉴를 선택할 때 열리는 성도보기 윈도에서 사용되었다.
  • 체크 박스: 사각으로 표현되며 여러 개중 하나 이상을 선택할 때 사용된다. 별바라기에서는 [보기][태양계대상...] 메뉴를 선택할 때 열리는 보기 윈도에서 사용되었다.
  • 컨트롤의 배경색: 편집 박스 또는 목록 박스의 배경색이 흰색이면 사용자가 편집하거나 마우스 클릭이 가능함을 뜻하고, 배경색이 회색이면 사용자가 편집할 수 없음을 뜻한다. 예를 들어 [도구모음][거리측정자] 메뉴를 선택하여 열리는 거리측정자 윈도에서 배경색이 흰색으로 나타나는 시야, 망원경 목록, 접안렌즈 목록은 사용자가 임의의 값을 입력하거나 마우스로 클릭할 수 있음을 뜻하고, 배경색이 회색으로 나타나는 배율, 구경, F/수, 초점거리, 시야는 단순히 정보를 보여주는 역할만하며 자료를 편집할 수 없다.
